Home Server with Raspberry Pi 4B

  1. Flash Raspberry Pi OS Lite to your SD card using Raspberry Pi Imager.
  2. Enable SSH: Place an empty file named ssh in the boot partition.
  3. Boot & Connect: Insert SD, power up, and SSH in: ssh pi@<pi-ip> (default password: raspberry).
  4. Update system: 
    sudo apt update && sudo apt upgrade -y
  5. Install Docker: 
    curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker pi
  6. Clone a server stack from GitHub and launch with Docker Compose: 
    git clone https://github.com/nextcloud/all-in-one.git
cd all-in-one
docker compose up -d
  7. Access the Web UI (see project README) to manage your server apps.
  8. Reset/Remove: To stop and remove all containers and data: 
    docker compose down -v
cd ..
rm -rf all-in-one

All code and instructions are open source and free on GitHub! Explore, fork, and contribute.

Example repo: nextcloud/all-in-one

Media Centre with LibreELEC (Kodi) or Jellyfin

  1. Download LibreELEC or Jellyfin from GitHub.
  2. Flash the image with Raspberry Pi Imager to your SD card.
  3. Boot your Pi and follow the on‑screen setup wizard.
  4. Enable SSH via Settings → Services (for remote config).
  5. Install add-ons (Kodi) or connect clients (Jellyfin) using the Web UI.
  6. Reset: To start over, re-flash your SD card with a fresh image using Raspberry Pi Imager.

All source code, add-ons, and guides are free and open on GitHub!

Repos: LibreELEC.tv | Jellyfin

Retro Gaming Console with RetroPie or Recalbox

  1. Download RetroPie or Recalbox from GitHub.
  2. Flash to SD card and insert into your Pi.
  3. Boot and run the setup wizard to configure controllers.
  4. Transfer ROMs (games) to /home/pi/RetroPie/roms via USB/network.
  5. Reboot and select your game system from the menu.
  6. Reset: To wipe all games and configs, re-flash the SD card with a fresh image.

All emulators and scripts are open source on GitHub. Join the community for support and mods!

Repos: RetroPie‑Setup | Recalbox

Home Automation Hub with Home Assistant

  1. Flash Home Assistant OS to your SD card.
  2. Boot and wait ~20 min for first setup (all code and docs on GitHub).
  3. Open http://<pi-ip>:8123 and create your account.
  4. Install integrations (Z‑Wave, Zigbee, MQTT, etc.) through the UI.
  5. Customize automations and dashboards as you like.
  6. Reset: Re-flash the SD card to start fresh, or use the "Wipe Data" option in the Supervisor panel.

All automations, add-ons, and integrations are open source and free on GitHub.

Repo: home-assistant/operating-system

Network‑Wide Ad Blocker with Pi‑hole

  1. Install Raspberry Pi OS Lite and update system.
  2. Install Pi-hole: 
    curl -sSL https://install.pi-hole.net | bash
  3. Follow prompts for setup and web admin.
  4. Point your router’s DNS to your Pi’s IP address.
  5. Access stats at http://<pi-ip>/admin.
  6. Reset/Remove: Uninstall Pi-hole and clean up: 
    sudo pihole uninstall
sudo apt purge pihole -y
sudo apt autoremove -y

Source code, blocklists, and web UI are open source and on GitHub, 100% free!

Repo: pi-hole/pi-hole

Weather Station with BME280 & Grafana

  1. Enable I²C: sudo raspi-config → Interface → I²C.
  2. Install sensor libraries: 
    pip3 install adafruit-circuitpython-bme280
  3. Clone example scripts: 
    git clone https://github.com/adafruit/Adafruit_CircuitPython_BME280.git
  4. Run test script: python3 examples/bme280_simpletest.py
  5. Install InfluxDB & Grafana: 
    docker run -d --name influx -p 8086:8086 influxdb
docker run -d --name grafana -p 3000:3000 grafana/grafana
  6. Reset/Remove: To remove containers and data: 
    docker stop influx grafana
docker rm influx grafana
docker volume prune -f

All code, libraries, and dashboards are open source and free on GitHub.

Repo: Adafruit_CircuitPython_BME280

Personal VPN Server with WireGuard

  1. Install Raspberry Pi OS Lite and update the system.
  2. Install WireGuard: 
    sudo apt install wireguard -y
  3. Generate keys: 
    wg genkey | tee key.priv | wg pubkey > key.pub
  4. Clone installer from GitHub: 
    git clone https://github.com/angristan/wireguard-install.git
cd wireguard-install
sudo bash wireguard-install.sh
  5. Follow prompts and import the config on your client device.
  6. Reset/Remove: To remove WireGuard: 
    sudo apt purge wireguard -y
sudo rm -rf /etc/wireguard
cd ..
rm -rf wireguard-install

Every line of code and setup script is open source and free on GitHub!

Repo: angristan/wireguard-install

Security Camera with MotionEye

  1. Install dependencies: 
    sudo apt update
sudo apt install python3-pip python3-dev libssl-dev libcurl4-openssl-dev libjpeg-dev -y
  2. Install MotionEye: 
    pip3 install motioneye
  3. Initialize configs: 
    sudo mkdir -p /etc/motioneye
sudo cp /usr/local/share/motioneye/extra/motioneye.conf.sample /etc/motioneye/motioneye.conf
  4. Start the service: 
    sudo meyectl startserver -b
  5. Access the web UI at http://<pi-ip>:8765 (default admin/admin).
  6. Reset/Remove: To uninstall and remove configs: 
    pip3 uninstall motioneye
sudo rm -rf /etc/motioneye /var/lib/motioneye

All software, configs, and community tips are on GitHub and free to use/modify!

Repo: ccrisan/motioneye
