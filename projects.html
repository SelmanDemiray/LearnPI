Home Server with Raspberry Pi 4B

  1. Install Raspberry Pi OS Lite on your SD card
  2. Enable SSH: create an empty file named ssh in the boot partition
  3. Boot Pi, SSH in: ssh pi@<pi-ip> (default password: raspberry)
  4. Update system: 
    sudo apt update && sudo apt upgrade -y
  5. Install Docker: 
    curl -fsSL https://get.docker.com | sh
sudo usermod -aG docker pi
  6. Clone OpenMediaVault Docker repo: 
    git clone https://github.com/whitechip/volumio-docker.git
cd volumio-docker
docker-compose up -d
  7. Access Web UI at http://<pi-ip>:9000 to manage shares

Repo: volumio‑docker

Media Centre with LibreELEC (Kodi)

  1. Download LibreELEC image from LibreELEC GitHub
  2. Flash it with Raspberry Pi Imager
  3. Boot Pi, complete on‑screen setup
  4. Enable SSH via Settings → Services
  5. Install addons via Kodi Add‑on repository

GitHub: LibreELEC.tv

Retro Gaming Console with RetroPie

  1. Download RetroPie image from RetroPie-Setup
  2. Flash with Raspberry Pi Imager
  3. Boot Pi, run first‑time wizard
  4. Configure controllers when prompted
  5. Use USB stick to transfer ROMs into /home/pi/RetroPie/roms
  6. Reboot and select your game system

GitHub: RetroPie‑Setup

Home Automation Hub with Home Assistant

  1. Flash Home Assistant OS image: HA OS
  2. Boot Pi, wait ~20 min for first install
  3. Open http://<pi-ip>:8123, create account
  4. Install integrations via UI (e.g., Z‑Wave, MQTT)
  5. Use YAML Editor add‑on to tweak configuration.yaml

GitHub: operating‑system

Network‑Wide Ad Blocker with Pi‑hole

  1. Install Raspberry Pi OS Lite, update system
  2. Run installer: 
    curl -sSL https://install.pi-hole.net | bash
  3. Follow prompts to set up blocking and web admin
  4. Point your router’s DNS to Pi’s IP
  5. Log into http://<pi-ip>/admin to view stats

Repo: pi-hole

Weather Station with BME280 & Grafana

  1. Enable I²C: sudo raspi-config → Interface ≥I²C
  2. Install sensor libs: 
    pip3 install adafruit-circuitpython-bme280
  3. Clone example script: 
    git clone https://github.com/adafruit/Adafruit_CircuitPython_BME280.git
  4. Run examples/bme280_simpletest.py
  5. Install InfluxDB & Grafana via Docker: 
    docker run -d --name influx -p 8086:8086 influxdb
docker run -d --name grafana -p 3000:3000 grafana/grafana

Repo: CircuitPython BME280

Personal VPN Server with WireGuard

  1. Install Raspberry Pi OS Lite, update system
  2. Install WireGuard: 
    sudo apt install wireguard -y
  3. Generate keys: 
    wg genkey | tee key.priv | wg pubkey > key.pub
  4. Clone setup script: 
    git clone https://github.com/angristan/wireguard-install.git
cd wireguard-install
sudo bash wireguard-install.sh
  5. Follow interactive prompts, then import conf on client device

Repo: wireguard-install

Security Camera with MotionEye

  1. Install dependencies: 
    sudo apt update
sudo apt install python3-pip python3-dev libssl-dev libcurl4-openssl-dev libjpeg-dev -y
  2. Install MotionEye: 
    pip3 install motioneye
  3. Initialize: 
    sudo mkdir -p /etc/motioneye
sudo cp /usr/local/share/motioneye/extra/motioneye.conf.sample /etc/motioneye/motioneye.conf
  4. Start service: 
    sudo meyectl startserver -b
  5. Access http://<pi-ip>:8765, default admin/admin

Repo: motioneye
