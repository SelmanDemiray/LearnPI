# Raspberry Pi 4B Setup Guide & Projects

This repository contains the source code for a simple website providing a setup guide and project ideas for the Raspberry Pi 4B.

## Features

*   **Setup Guide:** Step-by-step instructions for getting started with a Raspberry Pi 4B.
*   **Project Ideas:** A collection of projects you can build with your Pi, including home servers, media centers, retro gaming consoles, and more.
*   **Responsive Design:** Adapts to different screen sizes (desktop, tablet, mobile).
*   **Dark Mode:** Toggle between light and dark themes.
*   **Accessibility Features:** Includes skip links, ARIA attributes, and focus management for better usability.
*   **Project Filtering & Search:** Easily find projects based on category or keywords.
*   **Modal Popups:** Detailed project instructions are displayed in accessible modals.

## Technologies Used

*   HTML5
*   CSS3 (with CSS Variables for theming)
*   JavaScript (Vanilla JS for interactivity)
*   Font Awesome (for icons)

## How to Use

1.  Clone this repository:
    ```bash
    git clone <repository-url>
    ```
2.  Open the `index.html` file in your web browser to view the setup guide.
3.  Navigate to `projects.html` to explore the project ideas.

## Structure

*   `index.html`: Main setup guide page.
*   `projects.html`: Project showcase page.
*   `css/`: Contains stylesheets.
    *   `styles.css`: Main styles for layout, theme, and base elements.
    *   `components.css`: Styles for reusable components like alerts, tooltips, etc. (if applicable).
*   `js/`: Contains JavaScript files.
    *   `script.js`: Handles theme toggling, modal interactions, project filtering/search, and other dynamic behaviors.
*   `images/`: (Optional) Directory for any project images.
